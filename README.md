\# Actividad 8: Greedy



Este repositorio contiene la implementación en C++ de dos problemas resueltos mediante la estrategia Greedy.



\## Problemas

1\. Mochila Fraccional

2\. Cobertura de Antenas



\## Requisitos y Compilación

\- Compilador de C++ (g++)

\- Compilación: `g++ mochila_fraccional.cpp` y `g++ cobertura_antenas.cpp`
